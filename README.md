# Bulls and Cows

Учебная браузерная игра RS School на TypeScript с функциональным ядром и TDD.
Сборка и dev server — Vite, unit-тесты — Vitest.

В рабочем дереве реализованы выбор основания и длины, история попыток,
победа с подсчётом времени и общий топ-10 в localStorage. Рекорды сортируются
по числу попыток, затем по времени; каждая запись показывает настройки раунда.
После победы «Новая игра» возвращает к настройкам без перезагрузки.
Интерфейс доступен на английском и русском, со светлой и тёмной темой.
Язык и тема сохраняются в localStorage; переключение не сбрасывает раунд.

## Локальный запуск

Из корня проекта, с установленными Node.js и npm:

```sh
npm ci
npm run dev
```

Открыть адрес, который напечатает Vite. Точная версия Node.js в проекте не
закреплена; она должна удовлетворять `engines` установленных инструментов.

## Команды

| Команда                | Назначение                                     |
| ---------------------- | ---------------------------------------------- |
| `npm run dev`          | Локальный dev server                           |
| `npm test`             | Однократный запуск Vitest                      |
| `npm run test:watch`   | Тесты в режиме наблюдения                      |
| `npm run lint`         | Проверка ESLint                                |
| `npm run format:check` | Проверка форматирования проекта                |
| `npm run format`       | Переформатирование проекта; изменяет файлы     |
| `npm run build`        | Проверка TypeScript и сборка в `dist/`         |
| `npm run preview`      | Просмотр уже собранного `dist/`, после `build` |

## Структура проекта

- `src/game/core/` — пять обязательных функций и unit-тесты.
- `src/game/lifecycle/` — старт, обработка попыток, формирование итога и тесты.
- `src/game/leaderboard/` — чистое обновление и сортировка топ-10 с тестами.
- `src/view/pages/` — страницы настроек и игры.
- `src/view/ui/` — базовые элементы и компоненты игры, включая лидерборд.
- `src/view/infrastructure/` — универсальные операции JSON/localStorage.
- `src/view/service/` — загрузка, проверка и сохранение рекордов лидерборда.
- `src/view/app.ts` — переключение страниц и координация игрового сценария.
- `src/main.ts` — инициализация; `src/style.css` — оформление.
